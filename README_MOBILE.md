# Oddball Mobile

La version mobile est optimisée pour le mode paysage et peut être installée comme PWA lorsqu'elle est servie en HTTP/HTTPS.

Important : Android ne permet pas à une app web multi-fichiers de fonctionner correctement via une URL `content://` ouverte directement depuis certains gestionnaires de fichiers. Il faut servir ce dossier via HTTP/HTTPS (hébergement statique ou petit serveur local).

Une fois ouverte via HTTP/HTTPS dans Chrome/Brave : menu du navigateur > Ajouter à l'écran d'accueil / Installer l'application.
