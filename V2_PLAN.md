# Oddball Digital V2 — Claude Foundation

This branch is reserved for the V2 experiment based on the independently generated Claude prototype.

## Direction
- Claude prototype = technical and visual foundation candidate.
- Preserve the current main branch unchanged as the stable V1.
- Port the verified Oddball rules and visual knowledge from V1 into V2.
- Keep Claude's modular engine/effect-hook architecture.
- Evaluate Astra's event-driven animation cadence for selected interactions.
- Desktop/PC first. Mobile remains out of scope.

## Migration order
1. Import Claude prototype without altering behavior.
2. Add a rules-conformance test suite based on V1 decisions.
3. Fix confirmed divergences before visual changes.
4. Compare/port the authentic card visual language and useful board elements from V1.
5. Improve animation/event synchronization where Astra demonstrates a better pattern.
6. Re-evaluate Match AI and League lineup selection against V1.
7. Playtest V1 and V2 side-by-side before any decision to replace main.

## Non-negotiable
The current main branch must not be overwritten during the experiment.
